Add to Vercel Environment Variables
# From developer.linkedin.com → Your App → Auth tab
LINKEDIN_CLIENT_ID=your_client_id
LINKEDIN_CLIENT_SECRET=your_client_secret
# Must match exactly what you set in LinkedIn app
LINKEDIN_CALLBACK_URL=https://your-app.vercel.app/auth/linkedin/callback
Setup steps:
  • 1Go to developer.linkedin.com → Create App (needs a LinkedIn company page)
  • 2Products tab → Request Share on LinkedIn → approved instantly
  • 3Auth tab → add scope w_member_social and openid profile
  • 4Auth tab → add Redirect URL: https://your-app.vercel.app/auth/linkedin/callback
  • 5Copy Client ID + Client Secret → add the 3 env vars above to Vercel
  • 6Push updated code to GitHub → Vercel auto-redeploys → done!
